# PV concepts behind this project

- **ICSR:** Individual Case Safety Report, the basic unit of PV.
- **Four minimum criteria:** identifiable patient, identifiable reporter, at least one suspect drug, at least one adverse event.
- **Seriousness vs severity:** seriousness is outcome-based (death, life-threatening, hospitalisation, disability, congenital anomaly, medically important). Severity is intensity (mild, moderate, severe).
- **Expectedness:** whether the event is listed in the reference document (label/SmPC, or the Investigator's Brochure in trials).
- **Day 0:** the date the company first receives valid information; regulatory clocks start here.
- **SUSAR:** suspected unexpected serious adverse reaction (clinical trials).
- **Naranjo scale:** ten weighted questions giving a causality category. A structured aid, not proof.
- **MedDRA:** standard medical terminology with levels SOC > HLGT > HLT > PT > LLT. Licensed; this project uses a small fictional demo list.
- **Duplicate:** the same event reported more than once; found by matching patient, drug, event and dates.
- **Follow-up:** asking the reporter for missing or clarifying information.
- **QC and audit trail:** a second check of the case and a record of who changed what and when.
- **PBRER/PSUR:** periodic safety reports where non-serious post-marketing cases are summarised.
